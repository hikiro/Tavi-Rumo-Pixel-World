# Source provenance — 2026-11-23

This project is **Portalbound: Tavi & Rumo**, not Nokia Pixel Town Chronicle.

## Recovered from the previous Pixel World project discussion
- Tavi = boy explorer. Rumo = dinosaur companion.
- Earlier approved engine version was identified as **DINO Engine V5**, not the code committed here.
- Earlier dinosaur rig had nine semantic layers: tail, rear/front legs, neck, torso, spikes, head, jaw and forearm.
- Previously cited rig pivots: head/jaw **(20,21)**, tail **(43,29)**.
- Previously cited dinosaur demonstration: 7.2 seconds, 720×1280, 60fps and 432 frames; entry, anticipation, roar, chase, lunge, recovery.
- Previously cited Tavi Explorer V2: 96-pixel turnaround, 19 editable parts per direction, 14-color palette and 48-pixel compatibility sprites.
- User requests: idle, walk, run, jump, punch, block, fireball, fall, left/right turns; dinosaur companion rig, follow behavior, safe contact points, physics, and independent QC.

## Preservation rule
Any newly recovered original V5 file must go in a `legacy/original-v5/` directory with hash and provenance. Never silently overwrite it with the reconstruction.
