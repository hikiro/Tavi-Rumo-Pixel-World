## Integration separation
- `index.html` is the current **preview reconstruction**, not a source for recovering unseen original details.
- `legacy/original-v5/` should hold any authentic restored files.
- `experimental/` should hold variants and agent tests.
- `docs/` records provenance, bugs and certification.

## Continuous updates
Changes to the GitHub repository are committed only during explicitly executed sessions or via separately authorized automation. No silent autonomous changes have been enabled.
